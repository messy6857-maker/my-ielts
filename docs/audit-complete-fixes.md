## 优化实施

1. **统一账号生命周期与持久化**：避免多处重复实现和同一轮多次 JSON 序列化。
2. **抽出公共模考控制器**：阅读/听力共用按需载题、过期请求丢弃、计时、答案、多选评分、提交与记录逻辑。
3. **词库按章节加载**：22 个章节、3,674 个词条保持 ID、分组、顺序和内容不变；词条与例句/同义词资料分别拆分。提供加载、失败重试和快速切换时的过期请求保护。生成命令：`pnpm data:split`。页面插件只扫描 `.vue`，不再把数据源当成页面打包。词库页清理键盘监听，输入框不再被全局空格快捷键干扰，移除每次更新都重新加载音频的逻辑。
4. **升级工具链和依赖**：Vite 8、Vitest 5、Vue 3.5、VueUse 15、TypeScript 6、vue-tsc 3、ESLint 10、UnoCSS 66。使用 Vue 原生宏，移除旧宏插件和闲置工具；统一 pnpm 11.25 与锁文件，移除过时 npm 锁文件，GitHub Actions/Netlify 使用 Node 24.22.1。为上游仍引用旧版本的 xcode/数学格式工具配置精确的安全版本替换，并验证 CLI 与 UUID 接口兼容。完整 ESLint 通过；保留原生确认/提醒窗口对应的 9 条非阻断警告。
5. **写作草稿自动保存和恢复**：Task 1/Task 2 按账号和题目保存正文、剩余时间及更新时间；重新选题可恢复，恢复后计时保持暂停；成功存档后删除对应草稿。草稿纳入备份/同步白名单和结构校验；存储不足时显示保存失败，避免误认为草稿已经保存。

另外修复 404 图片的部署基址处理、打字页面未处理的 `@apply` 样式，以及英文扩展词解析中的回溯开销；后者与原解析器逐条比较 3,674 个词条，结果一致。
