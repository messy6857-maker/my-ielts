# 11f1c4f 后的修复与优化

本轮修复最终复查确认的 4 个问题，并完成两项写作代码优化。

## 修复

1. 同步凭据改为用户名与 token 的单个原子记录。自动/手动同步、退出前同步、AI 和个性化阅读请求均校验当前账号；其他标签页切换身份时，旧页面保存旧账号的本地数据并失效会话。旧页面退出也不会删除另一账号的新凭据和共享会话。
2. 作文草稿按题目分记录保存；原表作为旧格式兼容缓存。不同题目的并发保存不会互相覆盖，删除使用 tombstone 防止旧表恢复已删草稿；接收跨标签页变更时保留本页尚未保存的编辑。新记录参与同步、校验和备份，恢复旧格式备份或云端表时移除对应的旧分记录。
3. 错词记录增加可接受拼写数组，展示标题独立保存。词汇练习与错词复习共用答案规范化逻辑，并兼容旧记录的 `jeopardise / jeopardize` 格式。
4. 语音识别回调绑定录音轮次和识别实例。清除、重录、销毁后忽略旧结果；正常停止仍允许当前轮次最后的识别结果落地。

## 优化

- 大小作文按页签加载，带加载提示、失败重试和过期响应保护。writing 分块由 182.21 kB 降到 48.42 kB（gzip 从 63.08 kB 降到 19.36 kB）；这是该分块的构建体积对比，未测真实网络首载耗时。
- 抽取 useWritingSession / useEssayHistory，统一计时、草稿、账号切换和历史管理，题目展示及评分逻辑留在各自页面。

## 更新后行为

旧 token 没有记录所属账号，更新后需要重新登录一次；本地学习数据保留。不同题目的草稿独立存储；若两个页面同时修改同一道题，使用最后成功保存的版本。完整正文的旧格式兼容缓存会占用额外存储，空间不足时仍显示保存失败并支持重试。
