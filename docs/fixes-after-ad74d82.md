## 存储与兼容

- 新错词批次以单次 localStorage.setItem 为提交点。兼容缓存写入失败时，已提交记录仍然有效；未提交失败可重试。
- 检查点和新格式参与结构校验；支持 Web Locks 时自动压缩，不支持时保留日志保证并发安全。旧 UUID 操作标识只保留一次作为迁移去重信息，新操作使用 actor 水位。
- 备份和云同步输出合并后的表，避免上传页面操作日志；恢复旧表会清除对应附属记录，保持旧备份可用。
- 独立条目的修改可以合并；同一复习计划或掌握状态同时编辑时，按最后写入的条目处理。

## 构建

- 默认从完整仓库构建；缺少媒体会报错并返回非零退出码。
- Git tree 复用媒体的专用流程使用 PUBLIC_ASSET_INDEX，格式及职责见根 README。清单必须有 tree SHA、每个引用的 blob SHA/大小；本地已有文件需与清单匹配。MEDIA_FROM_GIT_TREE=1 不再跳过检查。
- 资源清单模式只验证源码与远端媒体契约；发布器仍需把对应媒体 blob 一起发布，不能直接发布缺少二进制媒体的源码副本 dist。
