# 三批修复与优化

基于 master `372914bf77d76a5533730acab8835ad038ad067c`。按用户最新要求，本轮只上传源码，不构建或发布线上版本。

## 第一批：功能修复

- 错词本改用独立操作记录，合并多标签页新增、重复错误计数和删除，避免整表覆盖；存储失败后可安全重试。
- 每日新词计数改为各页面独立分量，按词 ID 去重，保留账号、日期隔离和失败重试。
- 新记录格式纳入备份、云同步和结构校验；恢复旧版整表备份时移除过期附属记录。
- 旧 `/ielts` 路由跳转至现用听力页面并保留查询参数，删除重复且不再使用的数据集。
- `chef` 使用在线词典发音，避免请求不存在的本地音频。
- 资源整理脚本检查关键题图、讲义及音频，防止缺资源的源码副本被当作完整发布包。

## 第二批：性能优化

- 语法思维导图从内联 SVG 改为按主题加载独立文件，语法页面 JS 从 189.13 kB 降至 1.51 kB（Vite 未压缩体积）。
- 模考按阅读或听力加载对应数据，复用答案规范化逻辑。
- 整章词汇音频直接使用仓库原文件，Pages 目录避免重复复制约 257.9 MB；单词和模考音频仍保留。
- Android 构建阶段排除音频，保留题图与讲义，沿用在线音频解析方式。

## 第三批：清理维护

- 删除两个模板组件及三个模板测试/快照文件，清理组件声明。
- 21 份 Audacity 标签从 public 移至 maintenance/audio-tags，保留原内容。
- README 截图与标语保留在仓库，从发布目录排除。
- 更新根目录、页面、组件、词汇与音频维护文档。
- 仓库 About 网站链接修正为当前仓库的 Pages 地址。
